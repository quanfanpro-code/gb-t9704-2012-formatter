# 普通公文安全修复与发布实施计划

> **供自动执行使用：** 用户未授权子代理。本计划按 `executing-plans.md` 串行执行，步骤使用复选框跟踪。

**目标：** 将程序修复为安全、可信的一般普通公文排版工具，迁移到 .NET 10，完成测试、README、远端推送和双目录同步。

**架构：** 保留现有 WPF 界面和服务式处理链，在共同根因处移除破坏性 XML 改写。以“临时副本排版—最终结构校验—不覆盖发布”为主流程，检查报告只读取最终输出。

**技术栈：** .NET 10、WPF、WPF-UI 4.3.0、DocumentFormat.OpenXml 3.5.1、xUnit。

## 全局约束

- 只支持一般普通公文，不支持上行文、信函、命令和纪要专属格式。
- 页眉保持原样，各节页脚统一重建为 GB/T 9704—2012 页码。
- 公式、批注、修订、脚注、尾注、文本框和嵌入对象保持原样；相关段落跳过高风险改写并提示人工确认。
- 不改写表格文字和数字，不删除行列或对象。
- 修改已有文件前，完整备份到 `C:\Users\27651\BackUp\GB-T9704-2012排版工具_<时间戳>\` 并核验哈希。
- 中文 Markdown 和代码注释使用 UTF-8 with BOM；保存后检查乱码。
- 不增加新的运行时依赖，不覆盖或删除用户文件。
- 所有发布结论必须有当前执行的构建、测试、格式、漏洞、启动和端到端结果支持。
