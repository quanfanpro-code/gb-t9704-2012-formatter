# 普通公文安全修复与发布复核记录

## 复核结论

本轮变更可以进入发布验证。此前确认的致命问题均已在共同根因处修复，未发现新的阻断问题。

## 已关闭的阻断问题

1. 主窗口引用不存在的图标，程序无法启动：已移除失效引用，并增加真实窗口创建测试。
2. 表格数字被改成金额、尾部行列被删除：表格服务改为保持原内容和结构，危险实现已移除。
3. 换行、分页和段前分页被清除：停止重建段落文本和清除段落属性，回归测试已覆盖。
4. 机关标志被误判为标题：结构识别改为先定位发文字号，再识别其后的标题；版头保持原样。
5. 发文字号错误靠右：一般普通公文统一居中。
6. 有 OpenXML 结构错误仍显示“通过”：最终输出重新打开并校验，结构错误改为阻断错误。
7. 检查报告反映输入状态：改为根据最终输出重新分析，页码结论与输出一致。
8. 输出文件可能被覆盖：临时副本处理，最终采用不覆盖移动；失败副本单独保留。
9. 首页旧页脚被保留：所有节的首页、默认和偶数页脚均重建为标准页码；页眉保持。
10. 信函、命令、纪要名义支持但没有专属实现：界面、请求和规则模型已收敛为一般普通公文。

## 代码与复杂度复核

- 删除了无调用的文本重建、段落污染清理、运行合并、表格数字格式化、表格删行列和边框重建代码。
- 删除了未实现文种的枚举、识别分支和界面选择器。
- 没有增加新的运行时依赖或抽象层。
- 保留现有服务边界，修改集中在排版安全、结构识别、校验和发布流程。

## 测试覆盖

- 主窗口创建。
- 一般普通公文范围。
- 标题级别识别。
- 表格数字和尾部空行保持。
- 换行、分页和段前分页保持。
- 机关标志、发文字号和标题不误判。
- 页眉保持及所有旧页脚替换。
- 最终 OpenXML 结构有效及审计读取最终页码。
- 同名输出不覆盖。
- OpenXML 结构错误阻断。
- 批量审计输出目录和 UTF-8 BOM。
- 脚注引用和公式触发保守处理。

## 保留边界

- 不处理上行文。
- 不提供信函、命令和纪要专属格式。
- 表格保持原样，不自动统一其数字、边框或对齐。
- 复杂对象所在段落保持原样并进入人工复核。
- Word、WPS 最终分页和视觉效果仍需正式发文前人工查看。

## 发布门槛

发布前必须重新执行 Release 构建、全量测试、格式检查、依赖漏洞检查、真实启动检查、编码扫描和 Git 差异检查。任何一项失败都不得推送。
